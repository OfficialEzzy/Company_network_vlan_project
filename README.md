## Company Network VLAN Project

## Project Overview

A small company network designed and configured using Cisco Packet Tracer.

The network contains four departments, each assigned its own VLAN to provide network segmentation.

## VLANs

| Department | VLAN | Network |
|---|---:|---|
| HR | 10 | 192.168.10.0/24 |
| Finance | 20 | 192.168.20.0/24 |
| IT | 30 | 192.168.30.0/24 |
| Marketing | 40 | 192.168.40.0/24 |

## Network Devices
1 Cisco 2911 Router
2 Switches
8 PCs

## Testing
Devices within the same VLAN can communicate successfully.
Devices in different VLANs cannot communicate. 

## Tools Used
Cisco Packet Tracer
Cisco IOS CLI
VLANs
IPv4 Addressing
Ping

## Skills Practiced
VLAN configuration, IP addressing, subnetting, switch configuration, network segmentation, and basic network troubleshooting.
